## ✨ About

Crawrix simplifies your SEO analysis and improves your online visibility.
Provide the keywords you care about and it discovers relevant links for them,
saving hours of manual searching.

Made for **SEO specialists**, **content creators**, and **digital marketers**.

## 📦 Quick start

```bash
git clone https://github.com/babayaga0x/CRAWRIX-v4.0.0.git
cd CRAWRIX-v4.0.0
```

Full setup guides: [Backend](docs/backend-setup.md) · [Frontend](docs/frontend-setup.md)
